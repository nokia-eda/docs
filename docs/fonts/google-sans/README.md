# Google Sans

This directory contains the Latin WOFF2 subset of the Google Sans variable
font used by Draw.io diagrams in the documentation.

Source: [Google Fonts](https://fonts.google.com/specimen/Google+Sans)  
Version: 69  
License: [SIL Open Font License 1.1](OFL.txt)

The font file is an official, unmodified web-font asset served by Google
Fonts. It supports weights from 400 through 700.
